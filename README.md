# 🌸 مَـسْـكَة أتيليه | MASKA ATELIER

منصة وموقع تجارة إلكترونية متكامل واستوديو رقمي فاخر لتصميم وتنسيق وباقات الزهور الطبيعية، وخدمات التوصيل المبرد الذكي والتتبع الميداني بالـ GPS لمدينة طرابلس وليبيا.

---

## ✨ المميزات الرئيسية للمشروع

### 1. 🎨 استوديو التصميم المخصص والمصمم الذكي
- استوديو تفاعلي يتيح للزبون تنسيق باقته الخاصة، واختيار ألوان الورود، نوع التغليف الملكي (كرافت، زيتي، مخملي)، لون الشريط، وكتابة كرت الإهداء الممهور بالختم الشمعي الملكي.
- مصمم ذكي يقترح تركيبات وتوليفات زهور فورية حسب المناسبة والميزانية.

### 2. 💐 كتالوج الباقات وتوليفات الورود الدقيقة
- كتالوج باقات جاهزة مصنفة حسب المناسبات (أعياد ميلاد، زفاف، تخرج، اعتذار، شكر).
- عرض المكونات الحقيقية للباقة بعدد الورود من كل صنف (مثال: 10× جوري وردي + 5× توليب أبيض + 3× جبسوفيلا).

### 3. 📷 مخزون الورود الحية والتصوير متعدد الزوايا (360° Multi-Angle)
- إدارة مخزون الزهور مع توثيق كل صنف بـ 4 زوايا تصويرية أساسية:
  1. الزاوية الأمامية (Front View)
  2. الزاوية الجانبية (Side View)
  3. الزاوية العلوية وماكرو البتلات (Top / Petals View)
  4. تفاصيل الساق والأوراق (Stem & Foliage View)
- مستعرض زوايا تفاعلي ثلاثي الأبعاد للمنسق والزبون.
- قيود صارمة تمنع إدراج أي وردة في الباقات ما لم تكن مسجلة وموثقة في المخزون.

### 4. 🚗 لوحة السائقين والتتبع الجغرافي اللحظي (GPS & Google Maps)
- واجهة مخصصة ومبسطة لطاقم التوصيل الميداني تظهر بعد تسجيل الدخول.
- استعراض فوري للطلبات المسندة للسائق، مكان التسليم، والماهية الدقيقة للباقة.
- زر ملاحة مباشر يفتح إحداثيات موقع الزبون بدقة عبر Google Maps.
- خريطة تفاعلية لتحديد الموقع الحالي بنقرة زر عند الطلب.

### 5. 🎯 لوحة التحكم والإدارة الشاملة (Admin Dashboard)
- إدارة وتوجيه الطلبات وإسنادها لمنسقة الورد وسائق التوصيل المبرد عبر مودال مخصص.
- إدارة كوبونات الخصم والعروض الترويجية.
- إدارة الأسعار حسب مناطق ومدن التوصيل مع سجل تدقيق رقابي للتغييرات.
- تقييمات الزبائن وتفاعل الإدارة بالردود الرسمية.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **الواجهة الأمامية (Frontend):** Svelte 5 + Vite + SPA Routing.
- **الواجهة الخلفية (Backend):** Node.js 22 + Express.js 5 REST API.
- **قاعدة البيانات (Database):** MySQL 8.0+ (InnoDB, UTF8mb4) مع محرك الاستعلامات `mysql2/promise` ومجمع الاتصالات (Connection Pool).
- **التصميم والهوية:** CSS3 مخصص متجاوب بتدرجات الألوان الطبيعية (وردي مسكة، أخضر زيتي مريمي، عاجي، وأختام شمعية ملكية).

## 🚀 التثبيت والتشغيل المحلي

### 1. استنساخ المستودع (Clone)
```bash
git clone https://github.com/<your-username>/maska.git
cd maska
```

### 2. تثبيت الحزم (Dependencies)
```bash
npm install
```

### 3. إعداد متغيرات البيئة (.env)
قم بإنشاء ملف `.env` بناءً على `.env.example`:
```env
PORT=3000
DB_CONNECTION=mysql
DB_CLIENT=mysql2
DATABASE_URL=mysql://root:1234@127.0.0.1:3306/maska_db
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=maska_db
DB_USERNAME=root
DB_PASSWORD=your_password
```

### 4. إعداد قاعدة البيانات (MySQL)
قم بتنفيذ مخطط الجداول الشامل:
```bash
mysql -u root -p maska_db < database/schema_mysql.sql
```

### 5. بناء الواجهة الأمامية وتشغيل الخادم
```bash
# بناء ملفات الواجهة
npm run build

# تشغيل خادم مسكة الموحد
node server.js
```

الموقع سيعمل مباشرة على: **`http://localhost:3000`**

## 📜 هيكل المشروع
```text
├── assets/             # الرسومات والشعارات وأيقونات الورود والزوايا (SVG)
├── database/           # مخططات MySQL وهيكل قاعدة البيانات ومحرك الاستعلامات
│   ├── db.js           # وحدة الاتصال والاستعلامات غير المتزامنة (mysql2)
│   └── schema_mysql.sql# المخطط الشامل للجداول العشرين
├── public/             # الملفات الثابتة المعروضة مباشرة
├── src/                # كود الواجهة الأمامية (Svelte)
│   ├── components/     # المكونات المشتركة
│   ├── lib/            # عميل الـ API الموحد
│   ├── pages/          # صفحات النظام (Home, Studio, Cart, Admin, Driver, Login)
│   └── stores/         # مخازن الحالة العامة (Auth, Cart, Router)
├── .env.example        # نموذج متغيرات البيئة
├── package.json        # حزم المشروع والإعدادات
├── server.js           # خادم Express الرئيسي ومسارات الـ REST API
└── vite.config.mjs     # إعدادات مجمع Vite لـ Svelte
```
