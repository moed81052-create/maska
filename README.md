# 🌸 مَـسْـكَة أتيليه | MASKA ATELIER

منصة وموقع تجارة إلكترونية متكامل واستوديو رقمي فاخر لتصميم وتنسيق وباقات الزهور الطبيعية، وخدمات التوصيل المبرد الذكي والتتبع الميداني بالـ GPS لمدينة طرابلس وليبيا.

---

## ⚡ التشغيل السريع باستخدام دوكر (Docker & Docker Compose)

تم تجهيز المشروع بحاويات Docker كاملة ومستقلة تتولى تنزيل وتثبيت كافة المكتبات والاعتماديات لقاعدة البيانات والواجهة الخلفية والأمامية مع التهيئة التلقائية دون الحاجة لتثبيت أي متطلبات يدوياً:

### خطوة واحدة للتشغيل (One-Command Startup):
```bash
docker compose up --build -d
```

### ماذا تفعل الحاويات تلقائياً؟
1. **حاوية قاعدة البيانات (`maska_mysql`):**
   - تحميل محرك `MySQL 8.0`.
   - بناء الـ Database تلقائياً (`maska_db`) بترميز `utf8mb4_unicode_ci`.
   - استيراد كافة الجداول الـ 20 والبيانات الأولية (حسابات الإدارة، المنسقين، السائقين، مخزون الزهور بزواياه، الباقات، الكوبونات) عبر ملف `database/init_mysql.sql`.
   - تخزين دائم للبيانات في وحدة تخزين مستقلة (`mysql_data`).

2. **حاوية التطبيق (`maska_app`):**
   - بيئة مبنية على `Node.js 22 Alpine`.
   - تنزيل وتثبيت كافة مكتبات Node.js و Svelte و Vite و Express.
   - تجميع واجهة الـ SPA تلقائياً (`npm run build`).
   - تشغيل الخادم على المنفذ **`3000`** مع التحقق الصحي من جاهزية قاعدة البيانات أولاً.

3. **لوحة تحكم قواعد البيانات (`maska_phpmyadmin`):**
   - واجهة ويب بصرية جاهزة على المنفذ **`8080`** لمشاهدة وتعديل بيانات MySQL بسهولة.

### الروابط والمنافذ بعد التشغيل:
| الخدمة | الرابط | بيانات الدخول الافتراضية |
| :--- | :--- | :--- |
| **الموقع والتطبيق** | `http://localhost:3000` | مفتوح للجميع |
| **فحص صحة النظام** | `http://localhost:3000/api/health` | استجابة JSON فورية |
| **لوحة phpMyAdmin** | `http://localhost:8080` | المستخدم: `root` \| كلمة المرور: `1234` |
| **قاعدة بيانات MySQL** | `localhost:3306` | المستخدم: `root` \| كلمة المرور: `1234` |

### أوامر التحكم الإضافية بالدوكر:
```bash
# إيقاف الحاويات
docker compose down

# إيقاف الحاويات وحذف التخزين لإعادة التهيئة من الصفر
docker compose down -v

# متابعة السجلات المباشرة (Live Logs)
docker compose logs -f app
```

## ✨ المميزات الرئيسية للمشروع

### 1. 🎨 استوديو التصميم المخصص والمصمم الذكي
- استوديو تفاعلي يتيح للزبون تنسيق باقته الخاصة، واختيار ألوان الورود، نوع التغليف الملكي (كرافت، زيتي، مخملي)، لون الشريط، وكتابة كرت الإهداء الممهور بالختم الشمعي الملكي.
- مصمم ذكي يقترح تركيبات وتوليفات زهور فورية حسب المناسبة والميزانية.

### 2. 💐 كتالوج الباقات وتوليفات الورود الدقيقة
- كتالوج باقات جاهزة مصنفة حسب المناسبات (أعياد ميلاد، زفاف، تخرج، اعتذار، شكر).
- عرض المكونات الحقيقية للباقة بعدد الورود من كل صنف (مثال: 10× جوري وردي + 5× توليب أبيض + 3× جبسوفيلا).

### 3. 📷 مخزون الورود الحية والتصوير متعدد الزوايا (360° Multi-Angle)
- إدارة مخزون الزهور مع توثيق كل صنف بـ 4 زوايا تصويرية أساسية:
  1. الزاوية الأمامية (Front View)
  2. الزاوية الجانبية (Side View)
  3. الزاوية العلوية وماكرو البتلات (Top / Petals View)
  4. تفاصيل الساق والأوراق (Stem & Foliage View)
- مستعرض زوايا تفاعلي ثلاثي الأبعاد للمنسق والزبون.
- قيود مرجعية صارمة تمنع إدراج أي وردة في الباقات ما لم تكن مسجلة وموثقة في المخزون.

### 4. 🚗 لوحة السائقين والتتبع الجغرافي اللحظي (GPS & Google Maps)
- واجهة مخصصة ومبسطة لطاقم التوصيل الميداني تظهر تلقائياً بعد تسجيل دخول السائق.
- استعراض فوري للطلبات المسندة للسائق، مكان التسليم، والماهية الدقيقة للباقة.
- زر ملاحة مباشر يفتح إحداثيات موقع الزبون بدقة عبر Google Maps.
- خريطة تفاعلية لتحديد الموقع الحالي بنقرة زر عند الطلب.

### 5. 🎯 لوحة التحكم والإدارة الشاملة (Admin Dashboard)
- إدارة وتوجيه الطلبات وإسنادها لمنسقة الورد وسائق التوصيل المبرد عبر مودال مخصص.
- إدارة كوبونات الخصم والعروض الترويجية عبر نوافذ منبثقة تفاعلية دون نصوص مشتتة.
- إدارة الأسعار حسب مناطق ومدن التوصيل مع سجل تدقيق رقابي للتغييرات.
- تقييمات الزبائن وتفاعل الإدارة بالردود الرسمية.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **الواجهة الأمامية (Frontend):** Svelte 5 + Vite 8 + SPA Routing.
- **الواجهة الخلفية (Backend):** Node.js 22 + Express.js 5 REST API.
- **قاعدة البيانات (Database):** MySQL 8.0+ (InnoDB, UTF8mb4) مع محرك الاستعلامات `mysql2/promise` ومجمع الاتصالات (Connection Pool).
- **الحاويات والأتمتة (DevOps):** Docker Engine + Docker Compose + Alpine Linux.
- **الخرائط والملاحة:** Leaflet.js + OpenStreetMap + Google Maps Navigation.
- **التصميم والهوية:** CSS3 مخصص متجاوب بتدرجات الألوان الطبيعية (وردي مسكة، أخضر زيتي مريمي، عاجي، وأختام شمعية ملكية).

## 💻 التثبيت والتشغيل المحلي اليدوي (بدون دوكر)

إذا كنت تفضل التشغيل اليدوي على جهازك:

```bash
# 1. تثبيت حزم الواجهة والباك إند
npm install

# 2. نسخ ملف البيئة وضبط بيانات الاتصال
cp .env.example .env

# 3. استيراد المخطط والبيانات في خادم MySQL المحلي
mysql -u root -p maska_db < database/init_mysql.sql

# 4. بناء الواجهة الأمامية
npm run build

# 5. تشغيل الخادم
node server.js
```

## 📜 هيكل المشروع
```text
├── assets/             # الرسومات والشعارات وأيقونات الورود والزوايا (SVG)
├── database/           # مخططات MySQL وهيكل قاعدة البيانات ومحرك الاستعلامات
│   ├── db.js           # وحدة الاتصال والاستعلامات غير المتزامنة (mysql2)
│   ├── init_mysql.sql  # المخطط والبيانات الشاملة للتهيئة التلقائية في دوكر
│   ├── schema_mysql.sql# المخطط الشامل للجداول العشرين
│   └── seed_data.sql   # البيانات الأولية المستخرجة
├── public/             # الملفات الثابتة المعروضة مباشرة (صور الزهور والأصول)
├── src/                # كود الواجهة الأمامية (Svelte 5)
│   ├── components/     # المكونات المشتركة (Navbar, Footer, Modals)
│   ├── lib/            # عميل الـ API الموحد والمساعدات
│   ├── pages/          # صفحات النظام (Home, Studio, Cart, Admin, Driver, Login)
│   └── stores/         # مخازن الحالة العامة (Auth, Cart, Router)
├── .dockerignore       # استثناءات بناء حاوية دوكر
├── Dockerfile          # ملف بناء الحاوية متزامناً مع Svelte و Node.js
├── docker-compose.yml  # أوركسترا تشغيل التطبيق و MySQL و phpMyAdmin
├── .env.example        # نموذج متغيرات البيئة
├── package.json        # حزم المشروع والإعدادات
├── server.js           # خادم Express الرئيسي ومسارات الـ REST API وفحص Health
└── vite.config.mjs     # إعدادات مجمع Vite لـ Svelte
```
